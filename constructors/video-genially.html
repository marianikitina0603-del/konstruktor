Видео для Genially

Прямая ссылка на MP4 → настройки воспроизведения → готовый HTML-код. Для GitHub достаточно вставить адрес файла из репозитория.

1. Источник видео

GitHub-ссылка /blob/ автоматически преобразуется в адрес raw.githubusercontent.com. Репозиторий должен быть публичным.

2. Настройки

Если включено повторение, затемнение в конце отключается автоматически. Для автозапуска большинство браузеров требует выключенный звук.

3. Предпросмотр

Вставьте ссылку на видео
или выберите пример
0:00 / 0:00

4. Код для вставки

Скопируйте целиком и вставьте через «Вставить → Другие → Код» в Genially. Размер видеоблока задаётся в редакторе.

Важно

HTML5-видео без панели управления можно встроить по прямому общедоступному MP4. Некоторые варианты вставки Genially ограничивают запуск JavaScript и автозапуск; проверьте готовый слайд в режиме публикации. При выборе «Затемнение до окончания» эффект начинается за заданное время до конца ролика. На очень коротких видео затемнение стартует сразу. Ролик не переключает слайды самостоятельно.
